# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Single-page marketing site for **EG Capital Hub** ("Hub Especializado · Brasil · Portugal"), led by Emerson Gonzaga (Mogi Guaçu‑SP). The brand was previously FIRST; nothing from the old brand should reappear. All user-facing copy is Brazilian Portuguese — keep new text in pt-BR.

Stack: Next.js 16 (App Router, Turbopack) · React 19 · TypeScript (strict) · Tailwind CSS v4 · shadcn/ui primitives (Radix) · Zod 4 · sonner · lucide-react.

## Commands

```bash
npm run dev         # dev server at http://localhost:3000
npm run build       # production build (also type-checks)
npm run typecheck   # tsc --noEmit
npm run brand:logo  # regenerate emblem SVG paths, icons and OG image from docs/
npm run brand:map   # regenerate the dotted Atlantic map (Brasil ↔ Portugal)
```

There is no test suite and no linter. No env vars are required.

## Architecture

- **Content is data.** Brand, contact and legal constants live in `src/config/site.ts`; section copy lives in `src/content/*.ts`. Components only render. Change text there, not in JSX. Testimonial quotes are verbatim client words — don't rewrite them.
- **Server-first page.** `src/app/page.tsx` is a Server Component composing `src/components/sections/*`. Client islands only: `layout/Header`, `sections/CreditTabs`, `sections/TestimonialSlider`, `sections/ContactForm`, `brand/RevealObserver`, `brand/CountUp`, `legal/LegalToc`. Don't pass lucide components from content files into client islands (use string keys).
- **Navigation** uses plain `<a href="/#id">` so it works from the legal pages too. Sections that should highlight a menu item carry `data-nav="<id>"` (Header observes them).
- `src/app/(legal)/` holds `/politica-de-privacidade` and `/termos-de-uso`, built from `components/legal/*` (`LegalDocument`, `LegalBlocks`), with Header/Footer from the group layout.

### Theming (`src/app/globals.css`)

- Tailwind v4 is configured only in CSS. Fixed brand palette in `@theme` (`navy-*`, `gold-*`, `ivory-*`, `silver-*`); semantic shadcn tokens in `@theme inline`.
- **Dark-first, per-section themes:** `:root`/`.theme-navy` = navy tokens, `.theme-ivory` = ivory tokens, applied on a section (`<Section theme="ivory">`). The `dark:` variant means "not inside `.theme-ivory`". Never nest a navy block inside an ivory one. `text-gold` and `--gold-gradient` adapt per theme; buttons use the fixed `bg-gold-metal` for contrast.
- Brand utilities: `shell` (container), `numeral` (Cinzel lining figures — use for big numbers; Cormorant's old-style figures look wrong), `text-gold-gradient`, `grain`, `anim-delay-*` (animation delay; Tailwind's `delay-*` is transition delay).
- Fonts (`layout.tsx`): Cormorant Garamond = `font-serif` (headings), Montserrat = `font-sans` (body), Cinzel = `font-display` (wordmark/numerals).
- Scroll reveal: add `data-reveal` (optional `--reveal-delay`); one `RevealObserver` per page adds `.is-revealed`. Hidden state only applies under `@media (scripting: enabled) and (prefers-reduced-motion: no-preference)`.
- The fixed header uses `backdrop-filter`, which traps `position: fixed` descendants — keep overlays (mobile menu) outside `<header>`.

### Brand assets

- The emblem is traced from `docs/EG BRANCO NORMAL.png` by `scripts/trace-logo.mjs` into `src/components/brand/emblem-paths.ts` (generated — don't edit by hand). `EmblemSprite` (rendered once in the root layout) defines `<symbol id="eg-emblem">`; `Logo` references it via `<use>`, colored by `--logo-ink/--logo-line/--logo-gold` of the surrounding theme.
- `src/app/icon.svg`, `apple-icon.png`, `opengraph-image.jpg` and `public/brand/*` are also generated by the scripts.

### Contact form flow

There is no backend: `ContactForm` validates with Zod (`src/lib/validation.ts`), builds a pre-filled message (greeting from `content/contact.ts` + one `*Label:* value` line per field) and opens `whatsappLink(message)` (`src/config/site.ts`, `wa.me`) in a new tab.

- Fields: name, annual revenue (`contact.revenueRanges`) and need (`contact.needs`); the selects are validated with `z.enum` against those lists. The lead's phone number comes from the WhatsApp conversation itself.
- Keep the submit handler synchronous — `window.open` must run inside the click or the browser blocks it as a pop-up. The confirmation panel links to the same URL as a fallback.
- Changing form fields means updating `ContactSchema`, `ContactForm` (fields and message lines) and `content/contact.ts`.
